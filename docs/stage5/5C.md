## Goal

Add the pointer/touch interaction layer and the scrub feedback (playhead, progress, pill, keyboard). Do NOT populate the timeline DOM, do NOT wire the horizon toggle, do NOT remove the `#scrub` shim (all 5D).

1. **Pure helpers (exported, DOM-free, unit-tested):**
   - `idxFromX(px, railLeft, railWidth, n)` → `t = clamp((px − railLeft) / railWidth, 0, 1); return Math.round(t * (n − 1));`
   - `clampPillX(xLocal, trackW, pillW = 64, pad = 4)` → `Math.min(Math.max(xLocal − pillW / 2, pad), trackW − pad − pillW)`
2. **Deck-wide scrub surface** — handlers on `#deck` (the WHOLE deck height, any row, except interactive controls):
   - `pointerdown`: ignore `e.pointerType === 'mouse' && e.button !== 0`; ignore when `e.target.closest('button, [role=button], a, input')`; else `e.preventDefault()`, `deck.setPointerCapture(e.pointerId)`, mark scrubbing, remember whether playback was running, `pause()`, seek immediately (tap-to-seek), show the pill.
   - `pointermove`: store the latest `clientX`; schedule ONE `requestAnimationFrame` flush (never more than one seek per display frame).
   - `pointerup` / `pointercancel` / `lostpointercapture`: end scrubbing, hide the pill after a **900 ms** linger (cancel any previous timer); **do not auto-resume playback** (matches shipped pause-on-scrub).
   - Seek = `idxFromX(...)` against the **`#track-rail` rect** (cache it at gesture start; refresh on `resize` / `orientationchange` and after new wind data), then `requestFrame(idx)` (existing coalescer) and update feedback.
   - Keep `preventDefault()`/capture semantics so a thumb drifting ±80 px vertically mid-drag NEVER drops the gesture, and so Leaflet/the map never sees the events.
3. **Scrub feedback** — a single cheap helper (e.g. `updateScrubUi(idx)`) called from `showFrame()` (so play + programmatic frames move it too) and during scrub:
   - `#playhead`: `left = rail offset + t·(railWidth)` px, centred (the rail is already inset 11 px, so `left = 11 + t·(trackW − 22)` with `transform: translateX(-50%)` — reuse whatever is consistent with the 5B CSS; the playhead must sit exactly on the rail ends at idx 0 and idx n−1);
   - `#track-progress`: `transform: scaleX(t)`;
   - `#time-pill`: `textContent = ui.formatClockLocal(frames[idx].time)`; `transform: translateX(clampPillX(xLocal, trackW))` + `hidden = false` while scrubbing/playing, hidden after the linger at rest;
   - **no `getBoundingClientRect()` in the move path** beyond the once-per-gesture cache (the pill is fixed-width precisely so clamping needs no reads).
4. **Keyboard (accessibility)** — `#track` is `role="slider" tabindex="0"`; on `keydown`: `←/→` ∓/±1 frame, `PageUp/PageDown` ±4 frames, `Home/End` first/last; `preventDefault()`; update `aria-valuenow` and `aria-valuetext` (= `ui.formatClockLocal(frames[idx].time)`; 5D appends the day label). Keyboard seeking also pauses playback.
5. **Harness: re-enable `touch ergonomics`** in `tools/qa/stage4_check.py` (this is the pre-authorised delta): rewrite the group to drive a REAL pointer drag on `#deck` with Playwright's mouse API at 390×844 — press at ~20 % of the rail width, drag to ~70 % **with a mid-drag vertical wander of ±80 px**, release — then assert: (a) the displayed frame changed to the expected index (±1 frame), (b) the pill was visible during the drag and is hidden ≥1.2 s after release, (c) clicking `#play` does NOT change the frame index, (d) the play button is still ≥44 px. Keep the group's name and ok/FAIL reporting; remove the `DEFERRED` marker.
